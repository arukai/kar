# KAR — дауыс көмекшісі / голосовой помощник для Windows

**KAR** управляет компьютером голосом на **казахском** и **русском** языках: открывает сайты, программы и папки,
ищет в интернете и на YouTube, меняет громкость и яркость, управляет музыкой, ставит таймер, говорит погоду,
печатает текст, проверяет компьютер и отвечает на вопросы.

**KAR** компьютерді **қазақ** және **орыс** тілдеріндегі дауыспен басқарады: сайттар, бағдарламалар мен папкаларды
ашады, интернеттен және YouTube-тан іздейді, дыбыс пен жарықтықты өзгертеді, музыканы басқарады, таймер қояды,
ауа райын айтады, мәтін жазады, компьютерді тексереді және сұрақтарға жауап береді.

## Установка / Орнату

1. Установите Python 3.11–3.14 (галочка **Add python.exe to PATH**).
2. Запустите `setup.bat` — он поставит библиотеки и модели распознавания речи (қазақша ~42 МБ скачивается, русская лежит в `bundled/`).
3. Запустите `run.bat`.
4. *(по желанию)* `setup_ai.bat` — локальная нейросеть Ollama для ответов на вопросы.

## Использование / Қолдану

Скажите **«КАР»** и команду · нажмите на значок микрофона · или напишите команду в строке под чатом.
Все команды: [COMMANDS.md](COMMANDS.md). Язык меняется в **Баптаулар / Настройки**.

| Кнопка | Что делает |
|---|---|
| Ғаламтордан іздеу | следующая сказанная фраза → поиск в Google |
| Бағдарлама ашу | следующая сказанная фраза → открыть программу или сайт |
| Таймер / Дыбыс | таймер и громкость системы |
| Тоқтату / Ажырату | остановить речь; если нечего останавливать — выключить/включить микрофон |

Состояния (правый верхний угол): **КҮТУДЕ** (ожидание) · **ТІҢДЕУДЕ** (слушаю) · **ӨҢДЕУДЕ** (обработка) · **ЖАУАП БЕРУДЕ** (отвечаю) · **ҚАТЕ** (ошибка).

## Свободная речь и «мозг» (по желанию)

В **Баптаулар → ЖИ кілті** вставьте ключ любого сервиса — **сервис определится сам** по началу ключа, а модель выберется
из списка автоматически. Подойдут бесплатные ключи: NVIDIA — build.nvidia.com, Google Gemini — aistudio.google.com/apikey,
OpenRouter — openrouter.ai/keys; также DeepSeek, OpenAI, Claude. Это удобнее локальной Ollama, которой нужно много памяти.
С ключом KAR сама понимает, что фраза — команда («сағат қанша болып қалды екен» → «который час») или вопрос.
Свой сервер (LM Studio и т. п.) — поле `ai_base_url` в `config.json`. Без ключа всё работает как раньше.

## Word, Spotify и другие программы по цепочке

«**Открой ворд и напиши привет**» — KAR запускает Word с пустым документом (`winword /w`), ждёт его окно и печатает
текст туда, а не в чужое окно. «**Открой спотифай и найди песню люблю**» открывает поиск в Spotify; «… **и включи** песню
люблю» ещё и нажимает Play у первого результата (через UI Automation; отключается `"spotify_autoplay": false`).
Если кнопка не нашлась, KAR честно скажет, что поиск открыт, и оставит выбор вам. Для любой другой программы
(«открой калькулятор и напиши …») KAR запоминает новое окно и работает с ним.


## Казахский язык: что и как работает

* **Распознавание**: офлайн-модель Vosk `vosk-model-small-kz-0.15` + уточнение через Google (`kk-KZ`).
  Модель маленькая, поэтому для казахского лучше оставить включённым «Фразаларды Google арқылы нақтылау».
* **Голос**: Microsoft Edge `kk-KZ-AigulNeural` / `kk-KZ-DauletNeural` (нужен интернет). В Windows обычно нет
  офлайн-голоса на казахском — в офлайн-режиме KAR читает русским голосом.
* **Команды**: казахская фраза («ютубты аш») переводится в каноническую команду (`kazakh.py`), поэтому весь
  функционал доступен на обоих языках. Русские команды работают и при казахском интерфейсе.
* Словарь можно расширять: правила — в `kazakh.py`, фразы ответов — в `i18n.py`.

## Тесты

```
pip install pytest
python -m pytest tests
```
Тесты не требуют Windows, микрофона и интернета (всё подменяется заглушками, облачный клиент проверяется на
настоящем локальном HTTP-сервере): около 330 проверок — казахский разбор, маршруты, тексты, таймер, погода, напоминания,
рутины, файлы, реестр и микшер (на подменах), поведение движка.

## Приватность

Распознавание Vosk работает офлайн. Онлайн уходят только: аудио фразы в Google (если включено «нақтылау»),
текст ответа в Microsoft Edge TTS (если выбран Edge), запросы погоды (Open-Meteo), Википедии и нейросети Claude (если включено).
Личные файлы `config.json`, `history.json`, `kar.log`, `reports/` не публикуйте — они в `.gitignore`.

## Структура

`main.py` запуск и движок · `ui.py` окна · `actions.py` команды · `pcctl.py` уход за ПК · `kazakh.py` казахские команды · `i18n.py` тексты ·
`voice.py` речь · `automation.py`, `media.py` управление окнами и плеерами · `local_ai.py`, `ai.py` нейросети · `tools/` установка.
